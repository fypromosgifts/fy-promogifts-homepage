# FY PromoGifts Mug Sets

Standalone Cloudflare Pages site for `mugs.fypromogifts.com`.

## Cloudflare Pages configuration

- Project name: `fy-promogifts-mugs`
- Production branch: `main`
- Build command: none
- Build output directory: `mugs`
- Custom domain: `mugs.fypromogifts.com`

The page intentionally uses verified product photography hosted on `www.fypromogifts.com`. The product details and inquiry form remain tied to the existing FY PromoGifts catalogue and Formspree endpoint.
